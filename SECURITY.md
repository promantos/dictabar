# Security policy

## Supported versions

Security fixes are provided for the latest published Dictabar release.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's private
[security advisory form](https://github.com/promantos/dictabar/security/advisories/new)
and include:

- the affected Dictabar version and macOS version;
- reproduction steps;
- the security impact;
- any suggested mitigation.

Do not include real API keys, recordings, transcripts, Apple credentials, or
other people's personal data. Acknowledgement and remediation are best-effort;
no response-time or disclosure-time SLA is promised.
